# Cybersecurity Labs

Parcours en cybersécurité défensive (SOC / blue team) : analyse du trafic réseau,
journaux Windows, SIEM et triage d'alertes.

## Compétences
- Analyse de trafic réseau : tcpdump, Wireshark
- Analyse de journaux Windows : Event Viewer, requêtes XML, corrélation par Logon ID
- SIEM : requêtes SPL (Splunk), tableaux de bord Kibana / Elasticsearch
- Triage d'alertes SOC niveau 1 : vérifier, escalader ou classer
- Référentiel MITRE ATT&CK
