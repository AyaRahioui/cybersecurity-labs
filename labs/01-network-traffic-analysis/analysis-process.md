# Ma démarche d'analyse réseau

1. **Capturer** : choisir la bonne interface et filtrer dès la capture si possible.
2. **Identifier les acteurs** : qui est le client, qui est le serveur (qui initie la connexion ?).
3. **Regarder les protocoles** : ce qui est attendu et ce qui ne l'est pas.
4. **Chercher l'anormal** : volume inhabituel, ports étranges, destinations inconnues.
5. **Documenter** : noter l'heure, les IP, les ports et la conclusion.
